# SchoolManager.ParentApp

Flutter mobile app for parents (Android & iOS).

## First-time setup

The `android/` and `ios/` platform folders are generated by the Flutter CLI.
From this folder run:

```bash
flutter create --project-name school_manager_parent_app --org com.schoolmanager --platforms android,ios .
flutter pub get
```

`flutter create .` only adds missing files; it does not overwrite `lib/` or `pubspec.yaml`.

## Run

```bash
flutter devices          # list emulators / connected devices
flutter run              # run on the selected device
flutter test
```

iOS builds require macOS with Xcode (`cd ios && pod install` if needed).
